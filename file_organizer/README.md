# 📁 Python File Organizer

A simple Python automation script that organizes files in a folder based on their file type.

## Features

- Sorts files into Images, Documents, Videos, and Others
- Takes the folder path from the user
- Automatically creates folders if they are not present
- Uses only built-in Python modules
- Moves files automatically based on their extensions

## How to Run

1. Install Python
2. Open the project folder in VS Code
3. Run the script:

```bash
python file_organizer.py
